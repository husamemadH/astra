Astra TCP scaling experiment

Points show medians; vertical whiskers show the minimum and maximum across repetitions. Dashed lines show the single-threaded baseline. One MiB is 1,048,576 bytes. CPU percentages count one logical processor as 100%. Raw trials, interval boundaries, failure counts, and environment metadata are stored beside this report.

Server and client run in separate JVMs on the same host. Server window markers arrive over local process pipes after client phase events; use the recorded server elapsed time. Short windows amplify this boundary skew. Curves identify observed behavior, not by themselves the cause of a ceiling. Incomplete trials are excluded.
